DENTA.LAND — PORTFOLIO DEMO
=============================

ABOUT
Denta.Land is a dental clinic management SaaS interface focused on:
- patients and clinical records
- appointments and clinic scheduling
- treatment plans
- odontogram / tooth chart
- patient communication
- billing/revenue overview
- Calculator Builder for treatment estimates

IMPORTANT: DEMO VS REAL PROJECT STACK
-------------------------------------
This folder is a lightweight portfolio/demo build made with plain:
- HTML
- CSS
- JavaScript

The actual Denta.Land project stack to present in documentation / portfolio is:
- TypeScript
- Vite
- Bootstrap
- Sass (SCSS)

The HTML version exists only so the case can be opened instantly in a browser,
shown to clients, uploaded to simple hosting, and used as a visual prototype.

PAGES
-----
- login.html         Authentication
- dashboard.html     Clinic dashboard
- patients.html      Patient directory
- patient.html       Patient profile, odontogram and treatment plan
- calendar.html      Appointment calendar
- messages.html      Patient chat/messages
- calculator.html    Calculator Builder
- index.html         Redirects to login

PORTFOLIO POSITIONING
---------------------
Recommended project description:

"Denta.Land is a responsive dental clinic management interface designed for
daily operational workflows. The product brings together patient records,
appointments, treatment planning, communication, pricing tools and dashboard
analytics in one SaaS workspace.

Production frontend stack: TypeScript, Vite, Bootstrap and Sass."
